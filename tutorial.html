Como executar a documentação

Siga os passos abaixo para rodar a documentação localmente no seu computador. Cada passo mostra como conferir se deu certo antes de seguir para o próximo.

Se você já tentou e deu erro
“O termo 'mkdocs' não é reconhecido…”

Isso não significa que a instalação falhou. O Windows não encontra o mkdocs porque a pasta onde o pip o instalou não está no PATH — situação comum em computador de laboratório, onde não dá para alterar as variáveis do sistema.

A solução é não depender do PATH: chame tudo pelo próprio Python, com py -m. É o que este tutorial faz em todos os comandos.

py -m mkdocs serve
O que você vai precisar
Python 3.8 ou superior instalado
Conexão com a internet (para instalar os pacotes e carregar os diagramas)
A pasta do projeto — aquela que contém o arquivo mkdocs.yml
Recomendamos usar o VS Code
O VS Code tem terminal integrado e abre direto na pasta do projeto, facilitando os passos abaixo. Se não tiver, baixe em code.visualstudio.com.
1
Verifique se o Python está instalado

Abra qualquer terminal e digite o comando abaixo.

py --version
Deu certo se aparecer
Python 3.12.4

Se o py não for reconhecido, tente python --version. Se nenhum dos dois funcionar, o Python não está instalado: em máquina sem permissão de administrador, instale pela Microsoft Store (procure por “Python 3.12”), que instala no seu usuário e não pede senha de admin.

Se for instalar pelo python.org, marque a opção “Add Python to PATH” na primeira tela do instalador.

2
Instale os pacotes necessários
uma vez por máquina

Este comando instala o tema, as extensões de formatação e o suporte aos diagramas C4 — tudo de uma vez.

py -m pip install --user mkdocs-material pymdown-extensions plantuml-markdown
Deu certo se aparecer, no final
Successfully installed mkdocs-material… plantuml-markdown…

O --user instala apenas para o seu usuário, sem exigir permissão de administrador.

⚠
Um aviso amarelo pode aparecer — e pode ser ignorado
Se o pip avisar que a pasta Scripts não está no PATH, não é erro. É exatamente por isso que os comandos deste tutorial usam py -m.
3
Abra a pasta certa do projeto

A pasta correta é a que contém o arquivo mkdocs.yml — e não a pasta que contém essa pasta. Ao descompactar o projeto é comum ficar uma pasta dentro da outra com o mesmo nome; nesse caso, entre na de dentro.

▎ usando VS Code (recomendado)

Abra o VS Code, vá em Arquivo → Abrir Pasta e selecione a pasta que contém o mkdocs.yml. Você deve ver esse arquivo na barra lateral, junto com a pasta docs.

Em seguida abra o terminal integrado com Ctrl + ` (acento grave — tecla abaixo do Esc). Ele já abre dentro da pasta correta, então você pode pular o cd.

▎ usando o terminal do sistema

Abra o PowerShell (Windows) ou o Terminal (Mac/Linux) e navegue até a pasta, ajustando o caminho para onde você salvou os arquivos.

cd Downloads\ifvest-docs

Confirme que você está no lugar certo listando o arquivo de configuração:

dir mkdocs.yml
Deu certo se

o arquivo mkdocs.yml aparecer na listagem. Se disser que não foi encontrado, você está na pasta errada.

4
Inicie a documentação

Com o terminal aberto dentro da pasta do projeto, rode:

py -m mkdocs serve
Deu certo se aparecer
INFO - Serving on http://127.0.0.1:8000/

O terminal fica ocupado enquanto o site está no ar — isso é o esperado. Deixe essa janela aberta.

5
Abra no navegador

Acesse o endereço abaixo. A documentação vai carregar, e qualquer alteração que você salvar nos arquivos aparece automaticamente ao atualizar a página.

http://127.0.0.1:8000

Para encerrar, volte ao terminal e pressione Ctrl + C.

Se algo der errado

O termo 'mkdocs' não é reconhecido…
A pasta de scripts do Python não está no PATH. Use py -m mkdocs serve em vez de mkdocs serve.
O termo 'py' não é reconhecido…
Troque py por python em todos os comandos. Se nenhum dos dois funcionar, o Python não está instalado — volte ao passo 1.
No module named mkdocs
Os pacotes não foram instalados, ou foram instalados em outra versão do Python. Repita o passo 2 usando exatamente o mesmo comando (py ou python) que você usa para rodar.
Config file 'mkdocs.yml' does not exist.
Você está na pasta errada. Volte ao passo 3 e confirme com dir mkdocs.yml antes de rodar.
Unrecognised theme name: 'material'
O tema não foi instalado. Rode novamente o comando do passo 2 e confira se aparece mkdocs-material na lista de instalados.
Failed to load extension 'plantuml_markdown'
Falta o pacote dos diagramas. Instale com py -m pip install --user plantuml-markdown.
[Errno 10048] … address already in use
A porta 8000 já está ocupada, normalmente por outra execução que ficou aberta. Feche a outra janela do terminal, ou use outra porta: py -m mkdocs serve -a 127.0.0.1:8001 (e acesse esse mesmo endereço no navegador).
⚠
Sobre os diagramas C4
Os diagramas de arquitetura consultam o servidor público do PlantUML durante o carregamento, então precisam de internet liberada. Em redes institucionais que bloqueiam esse endereço, o site funciona normalmente e apenas os diagramas aparecem em branco — não é erro de configuração.
